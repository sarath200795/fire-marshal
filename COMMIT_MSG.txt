Add quotation gate before refill / defect resolution

A vendor quotation must now be submitted before a defective or refill-due
extinguisher can move to its next step. Submitting a quotation immediately
unlocks the progress action — no extra approval step. Applies to every item
in To Be Refilled AND every physical-defect item.

- extinguisherLogic: hasQuotation(ext) + needsQuotation(ext, today) helpers
  (reuse isToBeRefilled / isPhysicalDefect)
- firestore: submitQuotation() stores { amount, vendor, ref, notes,
  submittedAt, submittedBy } on the extinguisher doc via updateExtinguisher;
  markRefilledAndClosed and resolveDefects clear quotation:null so the next
  cycle requires a fresh quote. Not added to mirrorPayload (stays private).
- audit: WF_QUOTATION_SUBMITTED action + meta (shows in Audit Log)
- SubmitQuotationModal: new modal (amount* + vendor* + ref + notes), mirrors
  EditExtinguisherModal; prefills from an existing quotation
- RefillDue / PhysicalDefects / Repository: gate "Received by vendor" /
  "Resolve" / "Send to vendor" behind a quotation — show "Submit quotation"
  until one exists, then the progress button + a "Quoted" chip. Repository
  uses patchRows for optimistic update.
- Tests: 5 new cases for hasQuotation / needsQuotation (50 total)

No rules change needed — validExtinguisher uses hasAll (tolerates the new
quotation field); 26 rules tests still pass.
